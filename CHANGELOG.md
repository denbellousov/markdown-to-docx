# Changelog

Версии — по семантическому версионированию; источник версии — `__version__` в `md2docx.py`.

## 1.1.0 — 2026-10-29

Приложения для macOS и Windows, интерфейс на десяти языках, образцы на английском
(minor: новые возможности; разметка, оформление и ориентация — те же, что в 1.0.0).

**Внимание:** сообщения теперь на языке системы, а если перевода на него нет —
по-английски (в 1.0.0 — всегда по-русски). Прежний вывод — `MD2DOCX_LANG=ru`. Заглушка
на месте картинки тоже на языке интерфейса: по-английски `[image: alt]`.

Приложения:

- `md2docx_app.py` — точка входа приложений. Без ключей запускает интерфейс в браузере
  и показывает маленькое окно с адресом и кнопками «Открыть в браузере» и «Выйти»; выход,
  закрытие окна или `kill` останавливает сервер и удаляет временные файлы. Повторный запуск
  открывает уже работающий интерфейс; если порт 51536 занят чужой программой, берётся
  любой свободный, адрес — в окне. С ключами (`--port N`, `--no-browser`) работает как
  `md2docx_web.py`; файл, брошенный на значок в Windows, просто открывает окно.
- Сборка — PyInstaller по `packaging/md2docx.spec` в GitHub Actions
  (`.github/workflows/apps.yml`) с дымовым тестом собранного приложения
  (`packaging/smoke.py`). Файлы релиза: `md2docx-macos-arm64.zip`, `md2docx-macos-intel.zip`,
  `md2docx-windows-x64.exe`. Приложения не подписаны: при первом запуске macOS и Windows
  переспрашивают (как открыть — в README).
- Значок — `packaging/icon.png`.

Языки:

- Командная строка, страница в браузере и окно приложения — на английском (исходный язык),
  китайском (упрощённом), хинди, испанском, французском, арабском (справа налево),
  португальском (бразильском), русском, немецком и японском. Переводы — `locales/<язык>.json`.
- Язык: `MD2DOCX_LANG`, затем `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG`, затем язык ОС.
  Страница берёт язык браузера, в шапке — переключатель (выбор запоминается в браузере);
  ответы сервера — на языке страницы.

Образцы и картинки:

- `samples/01`–`07` — на английском. Русские оригиналы трёх из них, на которых держатся
  тесты кириллицы, — в `tests/fixtures/` (`02-tables.md`, `04-auto-landscape.md`,
  `06-blocks.md`).
- Картинка интерфейса в README — английская.
- `tests/verify.py` узнаёт заглушку картинки на любом языке интерфейса.

Исправлено:

- Интерфейс в браузере отклоняет путь загрузки с буквой диска Windows (`D:/a.md`): в Windows
  такой файл ложился вне каталога задания и не удалялся при остановке.

## 0.3.0 — 2026-10-22

Изменения по итогам 0.2.0 (minor: новый режим `--fix-fonts`, отказ перезаписать
файл, открытый в Word, разрез таблицы по `\newpage`, интерфейс в браузере; шапка таблицы
больше не повторяется).

**Внимание:** шапка таблицы теперь только в начале таблицы — на следующих страницах её
нет (в 0.1.0–0.2.0 она повторялась на каждой странице). У длинной таблицы читатель видит
названия колонок только на первой её странице.

Таблицы:

- `\newpage` или `\pagebreak` между строками таблицы режет её по целой строке: продолжение —
  отдельная таблица с новой страницы, без шапки, с теми же колонками (ширины — по всем
  строкам таблицы). Несколько разрывов — несколько частей, разрывы подряд — один разрез;
  в альбомную страницу таблица уходит целиком. Разрыв сразу под строкой-разделителем —
  таблица целиком с новой страницы. В 0.2.0 строки под разрывом выводились абзацами
  с `|`. Разрыв за последней строкой и перед новой таблицей — как раньше; в таблице внутри
  списка или цитаты разрыв игнорируется с предупреждением (в 0.2.0 в цитате он выводился
  строкой таблицы с текстом `\newpage`).
- Шапка таблицы больше не повторяется на каждой странице (`tblHeader` не ставится);
  она остаётся первой строкой, серой и полужирной. Конец таблицы
  держится вместе, если влезает в страницу (раньше — в страницу за вычетом повторённой
  шапки).
- Сверщик проверяет части таблицы своим разбором md: одна сетка, шапка только у первой
  части, разрыв перед каждой следующей; `tblHeader` у строки — расхождение.
- Известное ограничение LibreOffice описано в README («Строки таблицы у нижнего поля
  в LibreOffice»): если видимая на странице часть таблицы кончается ровно у нижнего поля,
  LibreOffice может не вывести следующие строки, хотя в файле они есть. Снятие повтора шапки
  этого не исправляет: LibreOffice 25.8.3.2 теряет строки в 10 вариантах из 71 и на результате
  0.2.0, и на 0.3.0; Word для Mac 16.114 — в 0 из 70. Обход — `\newpage` в таблице на границе
  строк или перед таблицей.

Запись результата и шрифты для Windows:

- Файл, открытый в Word, не заменяется: если рядом лежит замок Word, — отказ с кодом 1
  «<путь>: файл открыт в Word (рядом ~$…) — закройте его или запустите с --force»,
  в `convert()` — `FileExistsError`. Отказ и для нетронутого результата md2docx; `--force`
  перезаписывает. Имя замка — по замеру в Word для Mac 16.114: `~$` + имя без расширения,
  если в нём не больше 6 символов; 7 символов — без первого, 8 и больше — без двух первых;
  расширение то же (`отчёт.docx` → `~$отчёт.docx`, `отчёт-2026.docx` → `~$чёт-2026.docx`).
  Символы считаются после нормализации NFC: Word пишет имя замка в NFD; регистр
  не различается, как в APFS. У символьной ссылки замок ищется и рядом с файлом, на который
  она указывает.
- Новый режим `--fix-fonts FILE.docx …` и функция `fix_fonts(path, force=False)`: возвращают
  в таблицу шрифтов готового docx подсказки для Windows, которые Word для Mac стирает при
  сохранении (Helvetica Neue — `altName` Arial и класс `swiss`, Menlo — `altName` Consolas,
  и остальные поля, которые пишет md2docx); шрифту, который есть в тексте, но не в таблице
  шрифтов, запись добавляется. Остальные части файла не меняются, запись атомарная, права
  сохраняются; если менять нечего — «без изменений», файл не переписывается. Замок Word —
  отказ без `--force`; не docx, битый архив, нет таблицы шрифтов — ошибка этого файла,
  пакет идёт дальше; вместе с `-o`, `--landscape`, `--no-auto-landscape` — код 2.
  Защита от docx-бомбы: больше 512 МБ в распакованном виде (текст и стили — больше 64 МБ)
  или сжатие не deflate — отказ до распаковки; раньше файл в 634 КБ с 600 МБ нулей занимал
  1,2 ГБ памяти, теперь отказ за 0,1 с.
- Тесты `--fix-fonts` идут и на двух настоящих файлах из Word для Mac 16.114
  (`tests/fixtures/`: `samples/02` и `samples/06`, пересохранённые в Word; в свойствах
  документа автор и «кем изменён» заменены на «Тест»).

Интерфейс в браузере:

- `md2docx_web.py` (только стандартная библиотека Python) и `md2docx-web.command` для запуска
  двойным щелчком: страница http://127.0.0.1:51536/ — перетащить `.md`-файлы или папку,
  выбрать ориентацию (как флаги CLI), скачать `.docx` по одному или архивом. Результат тот
  же, что у CLI с теми же флагами. `.docx` на той же странице — исправление шрифтов, как
  `--fix-fonts`, на копии.
- Только 127.0.0.1, токен на каждый запуск сервера, лимиты — 60 МБ на файл и 200 МБ на
  выбор; хранится только последнее задание, остановка сервера удаляет всё. Тесты —
  `tests/test_web.py`.

## 0.2.0 — 2026-10-22

Исправления по итогам приёмки 0.1.1 и защита результата от перезаписи (minor: новый флаг
`--force` и новое поведение записи).

**Внимание:** результат перезаписывается молча, только если это нетронутый файл md2docx
с меткой. У результатов 0.1.0 и 0.1.1 метки нет — первая повторная конвертация поверх
них требует `--force`.

Таблицы и разделы:

- Места переноса в словах с дефисом — как у LibreOffice: после тире всегда, после
  дефиса — кроме дефиса между нецифрой и цифрой (`Ф-123456`, `АБ-2026`; в 0.1.1
  LibreOffice мог разорвать такой код посреди цифр). Влезает ли таблица в книжную
  страницу, решает минимум с этими переносами; если места хватает, даты и коды
  (`2026-10-22`, `АБ-2026-001`) остаются в колонке целиком, но таблицу в альбомную
  не уводят.
- Свободное место в таблице делится между колонками по объёму их текста, а не по самому
  длинному слову и строке: таблицы ниже.
- Подтягивание к автоальбомной таблице: кроме подписи с двоеточием и заголовков прямо
  над таблицей переезжает короткое вступление между заголовком и таблицей (до двух
  абзацев не длиннее 600 символов и одна линия) и, через такое же вступление, заголовок
  старшего уровня. Блоки без видимого содержимого подтягиванию не мешают; склейка двух
  широких таблиц считает только видимые блоки между ними. `samples/04` теперь даёт
  разделы «А, К».
- Отбивка 6 pt между заголовком и таблицей прямо под ним.
- Таблица не начинается внизу страницы шапкой с одной строкой тела и не кончается одной
  строкой на новой странице (keepNext на строках, которые не выше страницы). Цепочка
  держится, только если влезает: начало таблицы — в ¾ высоты текста, конец — в страницу
  под повторённой шапкой; иначе LibreOffice оставлял заголовок над таблицей внизу
  страницы одного.
- Таблица, у которой все ячейки шапки пусты, выводится без строки шапки.
- Документ, который кончается таблицей, завершается абзацем в 1 pt вместо 8 pt: таблица,
  дошедшая до низа страницы, не даёт пустой последней страницы. Так же таблица, за которой
  разрыв страницы: разделителя 8 pt под ней нет, и пустой страницы посреди документа тоже.
- `\newpage` или `\pagebreak` сразу под строкой таблицы — разрыв страницы, а не строка
  таблицы, сколько бы таких разрывов ни было в одной таблице. В серии маркеров ориентация
  и разрыв не теряют друг друга: маркер ориентации, за которым идёт `\newpage`, работает;
  `\newpage` перед маркером той же ориентации даёт разрыв. `\\newpage` и `&#92;newpage` —
  текст, и разрыв рядом с ними ставится на своей строке.
- Высота строки таблицы считается с картинками ячейки: строка с картинкой выше страницы
  не получает `cantSplit` и `keepNext`, цепочка из строк с картинками не держится, если
  не влезает.
- Блок кода — плашка с отступом текста от края; соседние блоки кода не сливаются в одну.
- Отступ списков и цитат растёт до восьмого уровня вложенности; таблица в глубокой
  вложенности не получает отрицательной ширины и не уходит за правое поле.

Ввод, ссылки, картинки:

- UTF-16 с BOM читается, BOM UTF-8 снимается; нулевые байты без BOM — ошибка «похоже
  на UTF-16 без BOM или двоичный файл — сохраните в UTF-8» вместо мусора в документе.
- H1 длиннее 255 символов больше не роняет конвертацию: заголовок в свойствах документа
  обрезается до 255 символов.
- Сноски `[^1]` и строки `[^1]: текст` остаются обычным текстом: раньше определение
  пропадало, а в тексте появлялась битая гиперссылка.
- Гиперссылки — только для `http:`, `https:`, `mailto:`, `tel:`. Другие схемы (`file:`,
  `data:`, `smb:`, `ms-msdt:`, `javascript:` …) — текст с предупреждением, относительные
  пути и `#якоря` — текст без предупреждения.
- Картинка не выше 0,8 высоты текстовой области страницы, в том числе в ячейке. Файл
  больше 50 МБ не читается — заглушка с предупреждением. Картинка вне каталога документа
  вставляется с предупреждением. В предупреждениях имя файла раскодировано из
  %-кодировки, `data:` URI обрезан; alt сохраняет сущности и `\`-экранирование.
- `&#12;` и `&#11;`, как и символы VT и FF в самом файле, дают пробел, а не склейку
  слов; front matter, закрытый `...`, распознаётся; незакрытый `<!--` внутри строки —
  с предупреждением; содержимое inline `<script>`/`<style>` не выводится; документ
  только из невидимых блоков и обрыв разбора по глубине вложенности — с предупреждением;
  inline-код в заголовке — кеглем заголовка.
- Символы, которых нет в Helvetica Neue, но есть в Arial (`→`), набираются Arial:
  Word для Mac рисовал их Times New Roman.

Запись результата:

- Запись атомарная (временный файл и замена): сбой не портит прежний результат.
  Результат только для чтения не заменяется и с `--force` («нет доступа»); символьная
  ссылка остаётся ссылкой — заменяется файл, на который она указывает, как в 0.1.1.
  Права прежнего результата сохраняются, жёсткие ссылки — нет (после замены это новый
  файл, 0.1.1 писал в прежний). Нужно право записи в каталог результата: без него —
  «нет доступа: <каталог>», хотя 0.1.1 в таком каталоге файл перезаписывал.
- Результат помечен (`dc:identifier` = `md2docx`). Существующий файл без метки или
  правленый после конвертации не перезаписывается: код 1 и подсказка `--force`. Новый флаг
  `--force`, в `convert()` — аргумент `force=False` (отказ — `FileExistsError`).
- Пакет: если результат входа совпадает с результатом более раннего входа того же
  запуска, поздний вход — ошибка, ранний результат остаётся.

## 0.1.1 — 2026-10-22

Исправления по итогам четырёх проверок (patch: поведение исправлено, нового нет).

- Остаток файла после списка глубины 10 или цитаты глубины 20 больше не теряется молча
  (`maxNesting` 100); пункты глубже девятого — на уровне Word 9.
- Ширины колонок считаются по бо́льшему из замеров Helvetica Neue и Arial: при подмене
  шрифта в Word на Windows слова в узких колонках не рвутся.
- URL в ячейке не задаёт колонке минимальную ширину; перенос после дефиса перед цифрой
  разрешён (даты и телефоны не уводят таблицу в альбомную без нужды); картинка и её
  заглушка в ячейке участвуют в ширине колонки.
- Таблица, не влезающая даже в альбомную страницу, рвёт слова только в самых широких
  колонках, номера и даты остаются целыми.
- Строка таблицы выше страницы может переноситься между страницами: раньше Word обрезал
  её текст, а LibreOffice выводил его за нижнее поле.
- Блок без видимого содержимого (пустая цитата, комментарий, `<br>`, `&nbsp;`, пустой `#`)
  не даёт пустого раздела и пустой страницы; маркер ориентации даёт новую страницу и
  рядом с автоальбомной таблицей; разрыв страницы перед маркером ориентации не даёт в Word
  лишней пустой страницы; `<!-- land scape -->` маркером не считается; на пустой файл —
  предупреждение.
- HTML-блоки: содержимое `<style>`/`<script>` не выводится, слова соседних элементов не
  склеиваются; незакрытый `<!--` скрывает остаток файла с предупреждением.
- Не падает на управляющих символах в заголовке и alt, на битой картинке и на `.` вместо
  файла; `-o`, совпадающий с исходником, — ошибка вместо перезаписи `.md`; ошибка одного
  файла не обрывает пакет; сообщения argparse и ошибки ввода-вывода — по-русски (текст
  самой ошибки ОС остаётся таким, как его дала система).
- Пустой `-o` — ошибка аргументов (код 2); раньше он молча игнорировался и результат
  ложился рядом с исходником.
- Предупреждение о маркере разрыва страницы внутри списка или цитаты называет разрыв,
  а не ориентацию.
- Маркеры списков — Arial (глифов `◦` и `▪` нет в Helvetica Neue); документ с `---` и
  пустой строкой в начале не теряет первый абзац как front matter; двойной пробел на
  месте вырезанного комментария схлопывается.

## 0.1.0 — 2026-10-21

Первая версия (minor: новый инструмент).

- Конвертер `md2docx.py`: CLI (`-o`, `--landscape`, `--no-auto-landscape`, `--version`)
  и функция `convert()` для вызова из Python.
- Оформление по эталонному документу Word: A4, поля 2 см, Helvetica Neue
  11 pt, встроенные стили заголовков Word 1–6.
- Таблицы на всю ширину текста: ширины колонок по реальной ширине текста (Pillow),
  повтор шапки на каждой странице, строки не рвутся между страницами.
- Ориентация страниц: маркеры `<!-- landscape -->` / `<!-- portrait -->`, разрывы
  `<!-- pagebreak -->`, `\newpage`, `\pagebreak`; автоальбомная ориентация для таблиц,
  не влезающих в книжную страницу без разрыва слов.
- Списки на настоящей нумерации Word, цитаты, блоки кода, гиперссылки, картинки.
- Совместимость с Word на Windows: замена Helvetica Neue → Arial и Menlo → Consolas
  через `fontTable.xml`, режим совместимости Word 2013+.
